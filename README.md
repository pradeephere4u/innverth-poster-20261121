A travel poster for **INNVERTH — where the rain falls up**: a cliff-top town at golden dusk whose one landmark is the Upfall, a river pouring skyward from a cliff pool into a deep teal sky, townspeople watching with umbrellas held upside down. Woven behind the scene is a guilloche-like lattice of thin upward-arching pale-gold lines, echoing the rising water — a background pattern invented for this place alone, light as a banknote's.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) copies `entry.png` to `/output/entry.png`, deterministically — every run writes the same bytes. To write somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
